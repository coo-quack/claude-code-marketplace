# Claude Code Marketplace by COO Quack!

A handy plugin for Claude Code. Give it a try!

## Usage

```bash
claude plugin marketplace add coo-quack/claude-code-marketplace
```

## Available Plugins

| Plugin | Description |
|--------|-------------|
| [sensitive-canary](https://github.com/coo-quack/sensitive-canary) | Blocks secrets and PII before they reach the Anthropic API |
| [do-not-compact](https://github.com/coo-quack/do-not-compact) | Reloads CLAUDE.md files into context after conversation compaction |
| [calc-mcp](https://github.com/coo-quack/calc-mcp) | MCP server with 21 tools for things AI is bad at: math, hashing, encoding, date arithmetic, and more |

## Install a plugin

```bash
claude plugin install sensitive-canary@coo-quack
claude plugin install do-not-compact@coo-quack
claude plugin install calc-mcp@coo-quack
```
